#### Apache Maven standard directory layout

```
The Apache Maven standard directory layout is a predefined, rigid folder structure that ensures
 consistency across all Maven projects. By adhering to this layout, Maven automatically locates
 source code, resources, and tests without requiring manual path configuration
```

##### Core Project Structure

```
At the root level of any Maven project, there is a pom.xml configuration file and a src directory.
A typical project looks like this:
```
```text
my-project/
├── pom.xml
├── src/
│   ├── main/
│   │   ├── java/
│   │   ├── resources/
│   │   └── webapp/
│   └── test/
│       ├── java/
│       └── resources/
└── target/

```

##### Directory Breakdown

```
-        pom.xml  - :  Located in the root directory; defines dependencies, plugins, and build profiles.

-     src/main/java/:  Houses all production Java source code, organized by package structure 
                       (e.g., com/example/app/Main.java).

- src/main/resources/: Stores production configuration files, property files, and XML configurations.
                       Files here are placed directly onto the runtime classpath

-    src/main/webapp/: Used for web applications to store static assets, HTML, JSP pages,
                       and the WEB-INF deployment descriptor

-      src/test/java/: Holds all unit and integration tests (such as JUnit or TestNG classes).

- src/test/resources/: Contains resources explicitly needed for testing purposes
                       (e.g., mock data profiles, test-specific properties)
                       
-             target/: Automatically generated by Maven during the build lifecycle. It holds compiled
                       .class files, temporary build reports, and the final packaged distribution
                        (like a JAR or WAR file)

```
